# PySR-BioModels

**Evaluating and Improving Symbolic Regression Methods for Biological Network Dynamics**

Google Summer of Code 2026 · National Resource for Network Biology (NRNB)

This site presents the final GSoC 2026 work product for the PySR-BioModels project, a benchmark for evaluating symbolic regression of biological ODE systems from curated BioModels SBML models.
